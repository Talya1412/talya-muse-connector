# Talya Muse Connector

Public website and privacy policy for the Talya Muse Connector Pinterest app.

- Website: https://talya1412.github.io/talya-muse-connector/
- Privacy policy: https://talya1412.github.io/talya-muse-connector/privacy.html

The connector is a personal, single-user integration between the owner's own Pinterest account (talya) and the owner's personal AI assistant, Muse, through the official Pinterest API.
